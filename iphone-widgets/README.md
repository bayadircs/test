# iPhone Widgets — VS Code + Scriptable

هذا مجلد تجارب لخمس ويدجتات Scriptable. الملفات داخل `iphone-widgets` في مستودع [bayadircs/test](https://github.com/bayadircs/test). ملفات المستودع الأصلية خارج هذا المجلد لا تحتاج أي تعديل. كود التجارب يعرض رقم الويدجت فقط.

## تعديل الكود على Windows

1. افتح مجلد `iPhone-Widgets` في VS Code، ثم افتح `iphone-widgets/widget-01.js` إلى `widget-05.js`.
2. غيّر النص أو التنسيق واحفظ الملف (`Ctrl+S`). هذه ملفات Scriptable؛ لا تعمل في Node.js أو معاينة VS Code مباشرة.
3. من PowerShell داخل `iphone-widgets` شغّل:

   ```powershell
   .\publish.ps1 -Message "Update widget 01"
   ```

   السكربت يفحص فرع `main`، يجلب حالة GitHub، ويضيف ملفات هذا المجلد المحددة فقط، ثم ينشئ commit ويدفعه. إذا ظهرت نافذة تسجيل GitHub فأكمل تسجيل الدخول. إذا سبق جهاز آخر بتعديل الفرع، يتوقف السكربت حتى تراجع الفرق وتزامن المستودع يدويًا. بعد أول نشر، كرر هذا الأمر لكل تعديل محفوظ. يمكن أيضًا فتح `publish.ps1` من VS Code وتشغيله في Terminal.

## إعداد Scriptable على الآيفون (مرة واحدة)

1. ثبّت تطبيق Scriptable المجاني وافتحه، وفعّل حفظ سكربتاته في iCloud إذا أردت أن تظهر نسخ `IW-widget-xx.js` فيه. لا تنقل أو تحذف سكربتاتك القديمة.
2. أنشئ سكربتًا جديدًا في Scriptable باسم `IW-Update-From-GitHub`، وانسخ إليه محتوى `update-iphone.js` كاملًا من [GitHub](https://github.com/bayadircs/test/blob/main/iphone-widgets/update-iphone.js). هذا الإعداد اليدوي يتم مرة واحدة.
3. شغّل `IW-Update-From-GitHub` **من داخل تطبيق Scriptable**. ينزّل ملفات `widget-01.js` إلى `widget-05.js` من الفرع `main` إلى مجلد محلي خاص بالتطبيق باسم `iphone-widgets-downloads`، ثم يعرض كود كل ملف للمراجعة. بعد مراجعة الملف، اختر تثبيت نسخته المُدارة باسم `IW-widget-01.js` وهكذا في مجلد Scriptable على iCloud. إلغاء التثبيت يترك النسخة المحلية المنزّلة فقط. السكربت لا يشغّل أي كود نزل من الإنترنت.
4. إذا لم يظهر السكربت الجديد في Scriptable فورًا، افتح التطبيق أو قائمة السكربتات من جديد وتحقق من إعداد iCloud. لا تمسح أي مجلد موجود.

## تشغيل أول ويدجت واختبار الربط

1. بعد نشر الملفات وتشغيل المحدّث ومراجعة الكود، افتح `IW-widget-01` في Scriptable واضغط زر التشغيل. يجب أن تظهر معاينة فيها `Widget 01`.
2. لإضافته للشاشة الرئيسية: اضغط مطولًا على الشاشة، أضف ويدجت Scriptable صغيرًا، ثم اختر السكربت `IW-widget-01` من إعدادات الويدجت. تحديث الويدجت على الشاشة تتحكم به iOS وقد يتأخر؛ معاينة Scriptable هي الاختبار الأسرع.
3. لتجربة تعديل: بدّل النص في `widget-01.js` على Windows، احفظ، شغّل `publish.ps1`، ثم شغّل المحدّث على الآيفون وراجع النسخة الجديدة قبل تثبيتها. افتح المعاينة مرة أخرى. هذا تسلسل نشر وتحديث يدوي، وليس مزامنة لحظية.

## LetsView

شغّل LetsView على Windows والآيفون، وتأكد أن الجهازين على شبكة Wi‑Fi نفسها، ثم ابدأ انعكاس شاشة الآيفون إلى اللابتوب. LetsView يعرض شاشة الآيفون للاختبار؛ التعديل يبقى في VS Code، والنشر يتم عبر GitHub، والتحديث يتم بتشغيل سكربت Scriptable يدويًا. [دليل LetsView](https://letsview.com/screen-mirroring).

## ملاحظات الحماية

- حساب GitHub والمستودع عامان، لذا لا تضع رموز دخول أو بيانات خاصة في ملفات الويدجت.
- المحدّث يقرأ خمسة أسماء ثابتة فقط من رابط المستودع، ويتحقق من HTTP 200، ويحفظ النص محليًا، ثم يعرضه قبل تثبيته. لا يستخدم `eval` أو `importModule` أو تشغيلًا تلقائيًا.
- إعادة التحديث قد تستبدل فقط نسخ `IW-widget-xx.js` التي وافقت على تثبيتها؛ لا تغيّر أي سكربت قديم باسم مختلف ولا تحذف مجلدات iCloud.
- تحتاج اتصال إنترنت عند `git push` على Windows وعند تشغيل المحدّث على الآيفون.
